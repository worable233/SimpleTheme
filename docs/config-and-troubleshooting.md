## 主题设置

### 首页文章数量

默认首页显示 6 篇文章。如需修改，在 **WordPress 后台 → 设置 → Simple Theme** 页面中调整「首页文章数量」字段。

### 主题色

主题支持自定义 Material Design 3 配色方案，通过 `src/lib/theme-config.ts` 配置主色种子色。

## 评论系统

评论功能通过 WordPress REST API 实现，支持：

- 嵌套回复
- 点赞
- 浏览器信息显示
- IP 归属地显示

### IP 归属地查询

IP 归属地使用以下 API 按优先级查询（失败则自动回退到下一个）：

| 优先级 | API | 说明 |
|--------|-----|------|
| 1 | [api2.upk.com.cn](https://api2.upk.com.cn) | 主接口，数据精确到区县级 |
| 2 | [ip-api.com](http://ip-api.com) | 回退接口，国外主机友好 |

如果两个接口均不可用，会返回「未知地区」。
